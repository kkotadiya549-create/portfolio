# Krunal — 3D Portfolio

Interactive 3D workstation hero (React Three Fiber) + full scroll portfolio
(About, Skills, Projects, Experience, Contact).

## Run locally
npm install
npm run dev

## Deploy to Vercel (free)
1. Push this folder to a GitHub repo.
2. Go to vercel.com -> New Project -> import the repo.
3. Framework preset: Vite. Build command: npm run build. Output dir: dist.
4. Deploy — you get a live URL in ~1 minute.

Or without git: run `npx vercel` inside this folder and follow the prompts.

## Edit your content
All real content (bio, skills, projects, experience, contact links) lives in
`src/data.js` — edit that one file to update the whole site.
Update the placeholder email/GitHub/LinkedIn in `contact` before deploying.
